## On AI coding

In the video I talked about how coding has started to feel weird. I'll be reviewing a pull request from someone on my team, and with coding agents everywhere now, it sometimes feels less like I'm reading their work and more like I'm reading whatever their AI generated.

I mentioned that I still don't trust it to build an entire feature from scratch. It needs a lot of handholding, and it can still put out questionable stuff. Bug fixes are where it actually helps me. The awkward part is the symmetry: while I'm reviewing code that someone else's AI helped write, my team is probably doing the same thing with mine.

I also talked about what that does to the craft. When I was learning to code, I'd get so stuck that I'd go to sleep and sometimes dream up a solution. Figuring it out yourself was the satisfying part. Lately it feels like we're sliding into a loop where AI writes more of the code and we mostly review it, and I wonder if we start losing the critical thinking that used to come from being stuck.

To extend on that, I've been thinking the review is becoming the job. If a first draft is cheap, the part that still matters is knowing what to throw out, what to keep, and which problems are worth sitting with until you can explain them. I use it for the small stuff. I still want the harder pieces to be ones I understand. I asked in the video what you think, and I'm still sitting with it.

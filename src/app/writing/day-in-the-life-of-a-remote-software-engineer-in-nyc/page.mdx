## On AI coding

But now that I mention it, is it just me, or has coding gotten really weird lately? I'll be reviewing code from someone on my team, and with how common coding agents are now, sometimes it feels like I'm really reviewing whatever their AI generated.

I still don't trust AI to build an entire feature from scratch. It needs a lot of handholding, and it can still put out some questionable stuff. For bug fixes, though, it's super useful. So while I'm reviewing code that someone else's AI helped write, my team is probably doing the exact same thing with mine.

That makes me wonder where software development is going. When I was learning to code, I'd get so stuck on a problem that sometimes I'd literally go to sleep and dream up a solution. There was something really satisfying about finally figuring it out yourself.

Now it feels like we're entering this weird loop where AI writes more of the code and we mostly review it. If that keeps going, I wonder if we start losing some of the craft, and the critical thinking that comes from solving these problems ourselves.

That's the part I'm still trying to figure out. What do you think?

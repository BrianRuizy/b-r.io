# Project guidance

Use the project skills when their subject is relevant:

- For interface polish, component details, and animation reviews, consult `.agents/skills/emil-design-eng/SKILL.md`. Apply it as context-sensitive guidance alongside this site's existing patterns, accessibility needs, and reduced-motion support.
- For work that explicitly uses or integrates shadcn/ui, consult `.agents/skills/shadcn/SKILL.md`. This project currently uses its own components and Tailwind tokens; prefer those by default, and do not introduce shadcn dependencies or migrate components just because the skill is available.
- For gesture-driven, spring-based, or Apple-style interaction work, consult `.agents/skills/apple-design/SKILL.md` as additional guidance.
